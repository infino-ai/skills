# Security Policy

## Reporting a vulnerability

**Please do not open a public issue for security vulnerabilities.**

Report security issues privately through GitHub's private vulnerability
reporting: open the **Security** tab on
<https://github.com/infino-ai/skills> and choose **Report a vulnerability**.

This repository holds instructions for coding agents. A skill that could lead
an agent to write insecure code, expose credentials or run unsafe commands
counts as a security issue here.

For a vulnerability in the Infino engine itself, report it on
<https://github.com/infino-ai/infino> instead.

Please include enough detail to reproduce the issue. We aim to acknowledge
reports within a few business days and will keep you updated on the fix.
